# Ajara Lawal: personal site

A one-page personal CV site built with plain HTML, CSS and JavaScript. There's no build step, so it runs anywhere, including Vercel.

## Files

```
index.html          the content (edit your text here)
css/styles.css      colours, fonts and layout
js/main.js          mobile menu, project filters, copy-email button
assets/favicon.svg  the little icon in the browser tab
assets/profile.jpg  your photo (add this yourself)
assets/Ajara-Lawal-CV.pdf   your CV (add this yourself)
```

## Colours

| Name       | Hex       | Used for                         |
|------------|-----------|----------------------------------|
| Blue-black | `#1D2033` | header, hero, contact, body text |
| Lilac      | `#C9B8E8` | buttons, portrait arch, accents  |
| Nude       | `#EBDCCF` | skills band, arch shadow         |

White is the page background, `#5B4A8B` (deep violet) is used for links, and `#686B78` (ash) for secondary text. To change any of them, edit the top of `css/styles.css`.

## Preview locally

Open `index.html` in your browser, or run a tiny local server from this folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.
